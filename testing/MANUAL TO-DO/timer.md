# Timer and menu bar manual guide

## Scaffold preview — pending

- [ ] Build/run Dayleft from Xcode on My Mac; record commit, macOS, Xcode, architecture.
- [ ] Menu bar shows the hourglass and fixed `3h 24m`, with no Dock icon.
- [ ] Click opens the panel near the selected status item; compare with the approved direction.
- [ ] Panel shows 3h 24m, finish 18:00, endpoints 09:00/18:00, and about 62% elapsed.
- [ ] Sample-day status makes fixed data clear; no unimplemented settings controls look active.
- [ ] Quit exits the app and removes its menu bar item.
- [ ] Inspect text contrast, VoiceOver naming, keyboard interaction, narrow/notched menu bars,
      multiple displays, Spaces/fullscreen, and system appearance. Record limitations honestly.

## Standalone MVP — not implemented

- [ ] Before start, during work, exact cutoff, and after-work behavior agree with the spec.
- [ ] Recurring hours persist across restart; today-only overrides expire as specified.
- [ ] Sleep/wake, manual clock/timezone changes, DST, and day rollover refresh correctly.
- [ ] Invalid/ambiguous work-hour input produces understandable handling.
- [ ] Login launch is opt-in and reflects the OS registration state.
- [ ] No connected account or network is required for ordinary timer use.

Provider and distribution guides should be introduced when their actual implementations exist.
